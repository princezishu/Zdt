## Data Flow

1. User interacts with Frontend (`app/src/components`).
2. Frontend makes REST API calls to Express (`server/src/routes`).
3. Express router delegates logic to Controllers (`server/src/controllers`).
4. Controller handles business logic, interacts with Supabase for DB/Auth, or Cloudinary for storage, then returns a JSON response to the client.
